# i18n: System locale for UI labels

## Summary

Replace all hardcoded Portuguese strings in Svelte components with a locale-aware lookup. Detect system language via `navigator.language`, support `pt` and `en`, default to `pt`.

## Architecture

Single file `src/lib/i18n.js` exports:
- `locale` — reactive state derived from `navigator.language` (first 2 chars)
- `t(key)` — returns translated string for current locale

Components replace hardcoded strings with `{t("key")}`.

## Scope

- UI strings only. Whisper transcription language unchanged.
- No backend changes.
- No i18n library — plain JS.
- No manual language selector — follows system locale.
